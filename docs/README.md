# LoraTrack Customer Documentation

This directory contains the official customer-facing documentation for deploying, operating, integrating, administering, and using LoraTrack.

## Intended Audience

- Customer project sponsors and service owners.
- Business and operational users.
- Organization administrators.
- Infrastructure and database administrators.
- Cybersecurity, architecture, and integration teams.
- Support and field commissioning personnel.

## Published Documents

- [Customer Technical and User Guide](LoraTrack-Technical-Documentation.pdf): product scope, user procedures, integrations, security model, field commissioning, and operational responsibilities.
- [Production Infrastructure and Operations Guide](LoraTrack-Deployment-Guide.pdf): production requirements, installation, configuration, scheduler operation, security hardening, monitoring, backup, recovery, and validation.
- [User Guide](user-guide.md): role-based application usage and administrative procedures.

The current publication version is recorded in [`VERSION`](VERSION). Stable HTML and Markdown editions are provided alongside each PDF for accessibility and controlled distribution.

Infrastructure sizing, availability objectives, retention periods, and recovery objectives must be approved for each production environment. References to security standards describe recommended alignment and do not constitute certification, customer acceptance, or an independent audit.
